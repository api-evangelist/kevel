## API Reference
- [Getting Started with Kevel](https://dev.kevel.com/reference/getting-started-with-kevel.md)
- [Decision API](https://dev.kevel.com/reference/request.md): The Decision API enables you to make ad requests without using ad code. By posting to a RESTful endpoint, Kevel's ad engine will return decision data and creative contents that can be used to serve ads in your application.You'll want to set the Content-Type in the header as application/json. The API will also accept text/plain to support applications that cannot change the content type
- [Response Parameters](https://dev.kevel.com/reference/response.md)
- [Multi-Winner Placements](https://dev.kevel.com/reference/multi-winner-placements.md)
- [Client-Side Requests and CORS](https://dev.kevel.com/reference/client-side-requests-and-cors.md)
- [Reporting API Overview](https://dev.kevel.com/reference/reporting-api-overview.md)
- [Reporting API](https://dev.kevel.com/reference/reporting-api-1.md)
- [Create Queued Report](https://dev.kevel.com/reference/create-queued-report.md): This endpoint makes a request in the Kevel database for the criteria passed in the parameters, and then returns a GUID that can be used to pull the finished report. Criteria can be specified for the report using an object titled "criteria". Report IDs will persist for 10 days.
